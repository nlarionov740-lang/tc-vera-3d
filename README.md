# ТЦ «Вера» — 3D-модель

Торговый центр «Вера», г. Верещагино, ул. Фрунзе, з/у 80. Открыть: https://nlarionov740-lang.github.io/tc-vera-3d/

Виды: #front, #back, #top, #iso, #area (округа: перекрёсток Фрунзе — Ленина), #night (ночь); ночная подсветка — #night=1 снизу вверх, #night=2 сверху вниз, #night=3 бра, #night=4 светодиодная лента.

Полёт с клавиатуры: ↑/↓ (W/S) — вперёд/назад, ←/→ — поворот, A/D — вбок, Q/E (PageDown/PageUp) — ниже/выше, Shift — быстрее.
